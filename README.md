# The Empty Box and Zeroth Maria - Bilingual Web Edition
# الصندوق الفارغ وماريا الصفرية

## Overview
This is a bilingual (English/Arabic) web-based reading platform for "The Empty Box and Zeroth Maria - Volume 01" (الصندوق الفارغ وماريا الصفرية - المجلد الأول) by Eiji Mikage, published by Yen Press.

## Features
- ✨ **Bilingual Support**: Full content available in both English and Arabic
- 📱 **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- 🎨 **Modern UI**: Beautiful gradient backgrounds and clean typography
- 🔄 **Easy Navigation**: Quick language switching and chapter navigation
- 📖 **Reader-Friendly**: Justified text, proper spacing, and comfortable reading experience
- 🌙 **RTL Support**: Proper right-to-left layout for Arabic text

## Structure
```
├── index.html              # Main English homepage
├── index_ar.html           # Main Arabic homepage

├── chapter_2.html          # 1st Time (English)
├── chapter_2_ar.html       # 1st Time (Arabic)
├── chapter_3.html          # 23rd Time (English)
├── chapter_3_ar.html       # 23rd Time (Arabic)
├── chapter_4.html          # 0th Time (English)
├── chapter_4_ar.html       # 0th Time (Arabic)
├── chapter_5.html          # 0th Time Part 2 (English)
├── chapter_5_ar.html       # 0th Time Part 2 (Arabic)
├── chapter_6.html          # 1st Time Part 2 (English)
├── chapter_6_ar.html       # 1st Time Part 2 (Arabic)
├── styles.css              # Main stylesheet
└── styles_ar.css           # Arabic-specific styles (RTL)
```

## How to Use
1. Open `index.html` in your web browser to start reading in English
2. Open `index_ar.html` to start reading in Arabic
3. Use the language switcher in the top-right corner to switch between languages at any time
4. Navigate between chapters using the "Previous" and "Next" buttons or return to the table of contents
